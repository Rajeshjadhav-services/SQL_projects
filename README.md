# Pizza Sales Analysis using MySQL

## Overview
This project analyzes pizza sales data from a 'Dominos' database using MySQL. It answers common business questions about revenue, order trends, and best-selling products.

## Tools Used
- MySQL
- MySQL Workbench

## Database
- **Database name:** `dominos`

The data is stored in related tables:
- **orders:** order date and time
- **order_details:** pizzas and quantity in each order
- **pizzas:** pizza size and price
- **pizza_types:** pizza name, category and ingredients

## Business Questions Answered
- What is the total revenue?
- What are the total number of orders ?
- Which pizzas and categories sell the most by quantity?
- What is most commonly sold pizza size?
- what is the highest priced pizza ?

## SQL Concepts Used
- Joins
- Subqueries
- Aggregate functions (SUM, COUNT, AVG)
- GROUP BY and ORDER BY

## Key Insights
- The "The Classic Deluxe Pizza" is the most selling pizza type.
- The most common sold pizza size is "L"
- Total orders are '21350'
- Total revenue generated is '$ 817860.05'
